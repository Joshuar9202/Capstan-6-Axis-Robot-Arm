# Capstan 6 Axis Robot Arm

I wanted to make a 6 axis robot arm, but making the standard one is boring. Thus after scouring the internet for unique designs, I found this: https://www.youtube.com/watch?v=cjIVU-O5PHo
Their design uses string for every joint and manages to compact the arm to allow the motors for the wrist to be placed within the first link. Thus, there are zero motors that are on the end effector. This keeps the weight low and makes it more agile. 
I used their concept to make design my own custom version of a entirely string actuated robot arm. The arm uses 3 stepper motors for the base, elbow, and turret joints, and uses 3 simpleFOC minis with small brushless gimbal motors for the wrist's roll, pitch, and yaw.
